# Cinema Tickets

Java 21+ template for the DWP cinema ticket purchase exercise.

Based on [dwp/cinema-tickets](https://github.com/dwp/cinema-tickets).

## Requirements

- JDK 21 or newer
- Apache Maven 3.9+

## Build and test

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
mvn clean test
```

## Status

Project instantiated from the official template. `TicketServiceImpl` is not implemented yet.
